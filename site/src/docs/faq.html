Questions fréquentes

Dois-je installer Arbor pour apprendre ?

Non. Arbor Web offre les mêmes fonctions d’apprentissage, depuis n’importe quel navigateur. L’application ajoute du confort : sa propre fenêtre, des raccourcis, des rappels natifs.

Est-ce gratuit ?

Apprendre seul est gratuit (Learning), avec un quota mensuel de générations ; Learning Plus l’augmente. Les équipes utilisent l’offre Business, facturée par utilisateur actif. Détails sur la page Tarifs.

Comment mes collaborateurs entrent-ils dans l’espace de l’entreprise ?

Sans lien d’invitation : autorisez leurs adresses ou le domaine de l’entreprise, et ils entrent dès leur connexion ; ou affichez un pass d’équipe (code court et QR, quelques minutes) pendant un briefing. Voir Arbor Business.

Je change d’ordinateur : comment retrouver mes cours ?

Télécharge une sauvegarde sur l’ancien (Réglages → Sauvegarde), puis restaure-la sur le nouveau. La synchronisation automatique est en préparation.

J’utilise un ordinateur partagé à l’université.

Utilise une fenêtre de navigation privée, ou télécharge une sauvegarde et efface les données du site avant de partir.

Y a-t-il une application iPhone ?

Elle est en préparation. En attendant, Arbor s’installe sur l’écran d’accueil depuis Safari : voir Sur téléphone.

Mon Mac a un processeur Intel.

L’application n’est pas encore construite pour les Mac Intel. Arbor Web y fonctionne pleinement.

Pourquoi Windows ou macOS m’avertit-il à l’installation ?

Les installateurs ne sont pas encore signés. Voir Windows et macOS pour passer l’avertissement et vérifier le fichier.

Le compagnon a dit « Information absente de tes sources ».

C’est voulu : il ne répond qu’à partir de tes cours. Ajoute une source dans Explorer, puis repose la question.

Une fiche a été refusée.

Arbor n’a pas réussi à produire une fiche qui respecte ses règles à partir des sources disponibles. Ajoute un document plus complet sur le sujet, ou reformule-le plus précisément.

Mon organisation voit-elle mon apprentissage personnel ?

Non. Les deux espaces sont séparés ; ton organisation ne voit que ce que tu fais dans son espace.
