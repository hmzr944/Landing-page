Partager et sauvegarder

Un formateur qui partage un parcours, un étudiant qui passe d’un ordinateur à l’autre : trois outils, selon ce que tu veux transmettre.

Partager un parcours par lien

  1. Ouvre le sujet, puis touche Partager.
  2. Arbor crée un lien qui contient le parcours lui-même : titres, notions, notes et fiches.
  3. Envoie le lien. La personne qui l’ouvre voit un aperçu, puis choisit Ajouter à mes apprentissages.
Ce qui est partagéCe qui ne l’est jamais
La structure du parcours, les notes, les fiches validées, les sources citéesTa progression, tes révisions, tes réponses, ton historique, ton compte

Le parcours voyage dans le lien, après le signe # : il n’est envoyé à aucun serveur, pas même à celui d’Arbor. Conséquence : toute personne qui a le lien peut lire le parcours. Ne partage pas de cette façon un contenu confidentiel.

Un très gros parcours (plusieurs documents complets) ne tient pas dans un lien : Arbor te propose alors d’exporter un fichier.

Exporter un sujet

Dans un sujet, Exporter télécharge un fichier .json que l’on peut importer sur un autre appareil ou transmettre.

Sauvegarder tout son apprentissage

Dans les réglages, rubrique Sauvegarde :

  • Télécharger une sauvegarde : un fichier avec tous tes sujets, ta progression et tes révisions ;
  • Restaurer un fichier : reprendre cette sauvegarde sur un autre appareil ou un autre navigateur.

Sur un ordinateur partagé (université, bibliothèque), ton apprentissage reste dans ce navigateur après ton départ. Télécharge une sauvegarde puis efface les données du site, ou utilise une fenêtre de navigation privée.
