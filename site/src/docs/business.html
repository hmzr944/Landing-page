Arbor Business

Arbor Business relie le savoir d’une organisation (documents, règles, savoir-faire de terrain) à l’apprentissage quotidien de ses équipes, et montre ce qui est réellement maîtrisé.

Créer une organisation

  1. Connecte-toi, puis ouvre Réglages → Espace professionnel → Créer une organisation.
  2. L’assistant de configuration te guide : nom, sites et équipes, premiers documents, accès de l’équipe.
  3. Avant de configurer, une découverte permet d’essayer Arbor Business sur des données d’exemple.

Faire entrer l’équipe, sans lien d’invitation

PortePourComment
Adresses autoriséesL’équipe stableDans Mon équipe, autorise une adresse, ou tout le domaine de l’entreprise (administrateur seulement), avec un rôle et un site. La personne se connecte avec son propre compte : dès que son adresse est vérifiée, elle rejoint l’organisation. Aucun lien, aucun mot de passe provisoire.
Pass d’équipeLe terrain : briefing, renfort, nouvelle consigneCrée un pass : un code de 6 caractères et son QR, valable 15 minutes (1 heure au plus), pour un nombre de places choisi et un site. La personne scanne ou tape le code dans Rejoindre une équipe, se connecte par un code reçu par e-mail, et arrive directement dans le bon espace.
  • Le rôle d’administrateur n’est jamais donné automatiquement.
  • Les domaines de messagerie publique (gmail.com, outlook.fr…) ne peuvent pas être autorisés en entier.
  • Le code d’un pass n’est affiché qu’à sa création ; après 10 essais ratés en une heure, un compte est bloqué pour les pass.
  • Les anciens liens d’invitation restent valables jusqu’à leur expiration.

Les rôles

RôlePeut
AdminTout configurer : membres, équipes, documents, validation, audit
ManagerSuivre son équipe, voir les fragilités, recommander des activités, relire des transmissions
ExpertValider les connaissances extraites des documents et relire les transmissions de son domaine
MembreApprendre, s’entraîner, consulter le savoir validé, proposer une transmission

Les droits sont appliqués par la base de données elle-même, pas seulement par l’interface : un membre ne peut pas lire ce que son rôle ne permet pas, même en contournant l’application.

Le socle souverain

Les connaissances extraites d’un document gardent leur provenance : le document, sa version, l’extrait exact. Un expert les valide avant qu’elles servent à former. Quand un document change, Arbor compare les versions et indique quelles connaissances et quelles personnes sont concernées par une revalidation.

Sur le Web, l’ordinateur et le téléphone

L’administration et le suivi se font aussi bien sur le Web que dans l’application. Sur téléphone, les membres retrouvent l’apprentissage quotidien et la consultation du savoir validé.
