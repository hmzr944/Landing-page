Premiers pas

En deux minutes : ouvrir Arbor, choisir un point de départ, et suivre la première notion de ton parcours.

1. Ouvrir Arbor

  • Sans installation : Arbor Web, depuis n’importe quel navigateur récent (Chrome, Edge, Firefox, Safari).
  • Sur ordinateur : Arbor Desktop pour Windows et macOS.
  • Sur téléphone : Arbor Web s’installe sur l’écran d’accueil, voir Sur téléphone.

2. Avec ou sans compte

Tu peux essayer Arbor sans compte : les cours d’exemple, l’import de documents, les révisions et la progression fonctionnent sur ton appareil.

Un compte gratuit ajoute ce qui passe par le serveur d’Arbor :

  • la génération d’un parcours à partir d’un sujet libre ;
  • les réponses rédigées du compagnon, et le jugement de tes explications écrites ;
  • l’accès à une organisation (Arbor Business).

3. Choisir un point de départ

Dans Explorer, écris ce que tu veux apprendre :

  • un sujet : « Les fractions », « Le protocole TCP » ;
  • une question : « Pourquoi le ciel est-il bleu ? » ;
  • un objectif : « Apprendre les boucles en Python ».

Indique ensuite ton niveau (je découvre, j’ai des bases, je veux approfondir) et ton intention (comprendre vraiment, réussir un examen, m’en servir au travail, par curiosité). Arbor adapte les explications et les exercices à ces deux choix.

Tu peux aussi partir d’un document : voir Importer des ressources.

4. Suivre la première notion

Arbor cherche d’abord des passages dans tes propres documents. S’il n’y en a pas assez, il s’appuie sur une source ouverte réelle (Wikipédia), citée avec son lien. La fiche de la notion est ensuite rédigée puis contrôlée : si elle ne respecte pas les règles pédagogiques d’Arbor, elle est refaite une fois, puis refusée plutôt que montrée imparfaite.

Le parcours commence toujours par une situation : un cas concret, avant le vocabulaire. C’est voulu : on comprend mieux une notion quand on a d’abord vu le problème qu’elle résout.
