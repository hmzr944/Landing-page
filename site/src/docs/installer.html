Windows et macOS

Arbor Desktop est la même application qu’Arbor Web, dans sa propre fenêtre, avec des raccourcis et des rappels natifs.

Configuration requise

SystèmeVersionFichier
Windows10 ou 11, 64 bitsArbor_…_x64-setup.exe (ou .msi pour un déploiement en entreprise)
macOS11 Big Sur ou plus, puce AppleArbor_…_aarch64.dmg

Sous Windows, Arbor utilise WebView2, déjà présent sur Windows 11 et sur la plupart des Windows 10 ; s’il manque, l’installateur le télécharge auprès de Microsoft.

Installer

Windows

  1. Télécharge l’installateur depuis la page Télécharger.
  2. Ouvre-le. Arbor s’installe pour ton compte, sans droits d’administrateur.
  3. Si SmartScreen affiche « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même.

macOS

  1. Ouvre le .dmg et fais glisser Arbor dans Applications.
  2. Si macOS refuse d’ouvrir l’application : Réglages Système → Confidentialité et sécurité, puis Ouvrir quand même.

Vérifier un fichier téléchargé

Chaque version publiée contient un fichier SHA256SUMS.txt. Compare l’empreinte de ton fichier avec celle qui y figure :

  • Windows (PowerShell) : Get-FileHash .\Arbor_2.0.0_x64-setup.exe
  • macOS (Terminal) : shasum -a 256 Arbor_2.0.0_aarch64.dmg

Si les empreintes diffèrent, ne lance pas le fichier.

Pourquoi ces avertissements ? Les installateurs ne sont pas encore signés par un certificat d’éditeur ni notarisés par Apple. C’est prévu ; les avertissements disparaîtront alors.

Raccourcis

RaccourciAction
Ctrl/⌘ + 1Mon espace
Ctrl/⌘ + 2 à 8Explorer, Mon apprentissage, Studio, Pratiquer, Ma connaissance, Compagnon, Progression
Ctrl/⌘ + KCompagnon Arbor

Ces raccourcis fonctionnent aussi dans Arbor Web sur ordinateur, sauf quand le navigateur les réserve.

Mises à jour

Pour l’instant, une nouvelle version s’installe en téléchargeant le nouvel installateur : tes données sont conservées. Les mises à jour automatiques viendront avec la signature.

Désinstaller

  • Windows : Paramètres → Applications → Arbor → Désinstaller.
  • macOS : glisse Arbor de Applications vers la Corbeille.

Pense à télécharger une sauvegarde avant : ton apprentissage personnel est enregistré sur l’ordinateur.
